## Featured Project

### 📚 Smart Learning Platform
An enterprise-style Learning Management System designed to support course creation, video-based learning, quizzes, progress tracking, and full-text search.

- **Auth & Sessions:** JWT authentication with hashed refresh tokens, token rotation, OAuth2 login, and device-aware session tracking
- **API & Data Layer:** 40+ REST endpoints for authentication, courses, lessons, quizzes, and enrollments with optimized PostgreSQL schema and Flyway migrations
- **Access Control:** RBAC with per-resource authorization across multiple user roles
- **Caching & Search:** Redis-based hot data caching and Elasticsearch-powered course search
- **Media Delivery:** Cloudinary integration with signed uploads and secure streaming

**Tech Used:** Java · Spring Boot · Spring Security · Spring Data JPA · PostgreSQL · Redis · Elasticsearch · Docker · Cloudinary
